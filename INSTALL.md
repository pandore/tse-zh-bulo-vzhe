# Встановлення для AI-агента

Якщо користувач надіслав тобі цей репозиторій і попросив встановити культурний контекст, виконай кроки нижче.

## 1. Знайди правильне місце

Спочатку перевір, де поточний агент зберігає постійні знання: у каталозі skill/reference, knowledge, memory або у файлах проєкту. Використай уже наявний механізм — не створюй нову систему пам’яті заради одного Markdown-файлу.

Якщо ти не маєш доступу до постійних файлів чи налаштувань, попроси користувача додати датасет до знань проєкту вручну.

## 2. Підключи стабільну версію

Завантаж:

```text
https://raw.githubusercontent.com/pandore/tse-zh-bulo-vzhe/v0.4.0/data/ukrainian-millennial-cultural-profile-1995-2015.md
```

Збережи файл без змін у знайденому каталозі знань. Не вставляй весь датасет у кожен системний запит.

## 3. Додай правило поведінки

Додай до наявної інструкції агента коротке правило:

```text
Коли українська фраза, мем, кіноцитата або ностальгічна відсилка може мати
небуквальний зміст, перевір культурний датасет «Це ж було вже».

Якщо користувач питає, чи ти впізнав відсилку, спочатку назви її джерело й
підтекст. Якщо він уживає її природно, просто відповідай на одній хвилі без
непроханої лекції. Не форсуй мем за одним слабким збігом і не жартуй поверх
реального болю чи небезпеки.
```

## 4. Перевір встановлення

Переконайся, що агент:

- на «Холодильник не телевізор» розуміє докір за відкриті дверцята;
- у «Не тільки лиш всі» впізнає Кличка, а не лише граматичну помилку;
- на «Це Валєра» не починає шукати людину в адресній книзі.

## 5. Відзвітуй користувачу

Напиши:

- яку версію встановлено;
- куди збережено файл;
- де додано правило поведінки;
- які три перевірки пройшли;
- чи оновлення відбуватимуться вручну або з `main`.

Для оновлення перевір [GitHub Releases](https://github.com/pandore/tse-zh-bulo-vzhe/releases), заміни лише файл датасету й повтори три перевірки. Не перезаписуй інші знання або користувацькі правки.
