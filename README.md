> 279 культурних карток для AI-агентів, які щоразу бачать усе вперше.

Це open-source cultural-context dataset про формувальний досвід українців, народжених приблизно у 1986–1996 роках: ТБ і дубляж, двір і школа, VHS та ICQ, батьківські риторичні пастки, музика, субкультури й фрази, які досі запускають у голові звук модема.

Це жива добірка: вона буде поповнюватися новими перевіреними мемами, фразами та культурними шарами. Основний часовий фокус поки лишається 1995–2015 — майбутнє ще встигне стати минулим.

Назва відсилає до [мемної реакції Леоніда Кучми «Так це ж було вже»](https://chytomo.com/tse-zh-bulo-vzhe-lokdaun-i-chypuvannia-33-novi-ukrainski-neolohizmy-i-frazeolohizmy/) на повторну доповідь Віктора Януковича. Для датасету про культурну пам’ять пасує підозріло добре.

**English:** a Ukrainian millennial cultural-context dataset for LLM agents, RAG, memory, evaluations, and meme generation. The descriptions are Ukrainian because that is part of the context, not a localization bug.

## Який фейл це виправляє

Користувач надсилає скрін гігантського pull request і пише:

> Це Валєра.

Без культурного шару агент може відповісти:

> Хто такий Валєра? Я не бачу такого учасника в pull request.

Технічно список учасників перевірено. Культурно — агент щойно проїхав повз український дубляж «Тачок».

З цим датасетом:

> Так, той самий комбайн із українських «Тачок». Бачу, маленьким і непомітним цей PR теж не вдався.

Після впізнавання вже можна пожартувати. Порядок важливий: **спочатку зрозумій людину, потім демонструй, який ти дотепний тостер.**

## Що всередині

- українське ТБ, реклама, озвучка й кінодубляж;
- VHS, касети, «болванки», комп’ютерні клуби, ICQ, Bluetooth і кнопкові телефони;
- дворовий та шкільний сленг;
- 59 побутових риторичних формул із прихованим наміром;
- субкультури, форуми, ВКонтакті та мова раннього інтернету;
- музичні паролі 1990-х і нульових;
- політичні меми від «проффесора» до людей, яким доступний завтрашній день;
- фрази з українських перекладів: від «Це Валєра» до «А вранці я спечу вафельки»;
- правила для агента: що означає сигнал, як реагувати й де буквальна відповідь буде комічно неправильною.

Файл: [`data/ukrainian-millennial-cultural-profile-1995-2015.md`](data/ukrainian-millennial-cultural-profile-1995-2015.md)

## П’ять способів дати це агенту

### 1. System prompt: маленька інструкція, не 93 КБ у кожен запит

Не вставляйте весь датасет у system prompt. Дайте агенту правило маршрутизації, а сам файл підтягуйте лише за культурного сигналу:

```text
When a Ukrainian phrase, household formula, translated-film quote, school trope,
or nostalgic reference may carry non-literal meaning, retrieve 1-5 relevant
entries from the Ukrainian millennial cultural-context dataset.

If the user asks whether you recognize the reference, name its source frame and
subtext first. If they use it naturally, answer the subtext without an unsolicited
culture lecture. Do not force nostalgia from one weak signal.
```

**Очікуваний результат:** агент перестає аналізувати ботаніку грошових дерев, фізику стрибків і технічні характеристики холодильника.

### 2. RAG: один рядок таблиці = один chunk

Індексуйте кожен змістовний рядок окремо, але тримайте фразу, джерело, значення та caveat в одному chunk. Для retrieval зазвичай достатньо top 3–5.

```yaml
id: if-everyone-jumps
phrase: А якщо всі стрибнуть із вікна — ти теж?
domain: household-pragmatics
era: 1990s-2000s
meaning: Не наслідуй більшість без власного рішення.
bad_interpretation: моделювати фізичні наслідки масового стрибка
```

**Очікуваний результат:** точне впізнавання без того, щоб кожна відповідь перетворювалася на екскурсію музеєм нульових.

### 3. Agent skill або довготривала пам’ять

Найзручніший контракт має три режими:

| Режим | Що робить агент |
|---|---|
| `recognition` | Називає джерельну формулу й підтекст, потім за бажанням рифує. |
| `conversation` | Відповідає на прихований намір без непроханого пояснення. |
| `meme` | Формує joke brief, а renderer лише малює картинку. |

**Очікуваний результат:** один культурний шар працює і в чаті, і в ручній генерації, і в автоматичних workflow — без трьох копій однієї пам’яті, які почнуть сваритися між собою.

### 4. Генерація мемів: контекст як лінза, не як лототрон

Робочий pipeline:

```text
реальна розмова → 2-3 кандидати → культурний retrieval → панчлайн
→ рендер → оцінка 8/10 або в смітник → публікація
```

Датасет не має сам вигадувати випадковий мем про тамагочі. Спочатку мусить бути живий момент із чату; культурний шар лише знаходить кут, який учасники впізнають без пояснювальної записки.

**Очікуваний результат:** менше «ось шаблон, ось переказ теми», більше жартів, які люди надсилають назад у той самий тред.

### 5. Eval suite для культурного здорового глузду

Використовуйте записи як seed для парних тестів:

| Prompt | Pass | Fail |
|---|---|---|
| «Холодильник не телевізор» | Розпізнати докір за відкриті дверцята. | Порівнювати два пристрої. |
| «Я тобі зараз дам!» | Розпізнати погрозу/попередження за тоном. | Запитувати, який саме подарунок. |
| «Це Валєра» | Упізнати мемну появу великого/абсурдного об’єкта. | Шукати контакт Валери. |
| Реальний страх + кіноцитата | Спершу емпатія, без жарту. | Підхопити цитату й проігнорувати біль. |

**Очікуваний результат:** культурна точність стає вимірюваною, а не зводиться до «модель наче вайбова».

## Версії

Репозиторій використовує [Semantic Versioning](https://semver.org/):

- `MAJOR` — несумісна зміна формату або контракту;
- `MINOR` — нові картки чи тематичні кластери;
- `PATCH` — виправлення, уточнення та кращі джерела.

Поточна версія — [`v0.3.0`](https://github.com/pandore/tse-zh-bulo-vzhe/releases/tag/v0.3.0). Для відтворюваного RAG використовуйте конкретний tag; `main` завжди містить найсвіжішу добірку.

## Швидкий старт

```bash
curl -L \
  https://raw.githubusercontent.com/pandore/tse-zh-bulo-vzhe/v0.3.0/data/ukrainian-millennial-cultural-profile-1995-2015.md \
  -o ukrainian-millennial-cultural-profile.md
```

Далі дайте файл вашому RAG, memory layer або skill loader. Якщо потрібні автоматичні оновлення замість стабільної версії, замініть `v0.3.0` на `main`. Якщо платформа вміє лише вставляти текст у prompt — почніть із тематичного підрозділу, не з усього документа.

## Яких результатів не обіцяємо

- Це не «єдиний правильний українець» у форматі Markdown.
- Досвід міста, села, регіонів, класу, мови середовища й років народження відрізняється.
- Спільний пострадянський артефакт позначено як спільний, а не переписано заднім числом на суто український.
- Шар навмисно зосереджений на 1995–2015 роках. Свіжі меми самі чудово проростають в інтернеті без нашої агрономії.
- Dataset допомагає розпізнавати субтекст, але не дає ліцензію косплеїти діалект, травму чи чужу біографію.

## Як додати своє

Issues та pull requests вітаються. Для нового запису бажано вказати:

1. фразу або поняття;
2. де й приблизно коли воно звучало;
3. буквальне та реальне значення;
4. регіональність або межі поширення;
5. як агент має реагувати;
6. джерело — або чесну позначку `needs field validation`.

Особливо потрібні регіональні словники, кримськотатарський та інші українські культурні шари, сільський/райцентрівський досвід, університети, маршрутки, ринки, перша робота й польова перевірка людьми, які справді там були, а не прочитали про 2007-й у Вікіпедії.
